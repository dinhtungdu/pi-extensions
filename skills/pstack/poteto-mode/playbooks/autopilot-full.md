# Autopilot

Run the authorized implementation to a verified local result.

- Read the task, repository policy, and current state.
- Derive the smallest end-to-end change and explicit acceptance checks.
- Use `/skill:architect` only for a real cross-boundary design choice.
- Delegate one bounded writer with the configured workflow role, or edit directly when delegation adds no execution value.
- Inspect the diff, run lint and proportionate tests, then use independent review for risky work.
- Correct routine failures in the same run.
- Report local completion or the exact blocker.

External publication and lifecycle actions remain with the retained parent and require exact authority. Do not create watchers, queues, or recovery state for a bounded task.
